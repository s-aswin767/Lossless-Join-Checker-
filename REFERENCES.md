# References

1. Abraham Silberschatz, Henry F. Korth, S. Sudarshan. *Database System Concepts*. McGraw-Hill. Chapters on relational design, functional dependencies, and normalization.
2. Ramez Elmasri, Shamkant B. Navathe. *Fundamentals of Database Systems*. Pearson. Sections on schema decomposition and lossless join testing.
3. Raghu Ramakrishnan, Johannes Gehrke. *Database Management Systems*. McGraw-Hill. Relational design and dependency-preserving decomposition.
4. Jeffrey D. Ullman, Jennifer Widom. *A First Course in Database Systems*. Pearson. Functional dependencies and chase-style reasoning.
5. ISO/IEC 9075. *Database Language SQL* — official SQL standard family reference for relational query semantics.

The implementation in this project is an educational, bounded tableau simulator intended to make the reasoning visible rather than a replacement for a production schema-design verifier.
